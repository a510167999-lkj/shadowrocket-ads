# shadowrocket-ads

精简版小火箭配置：LingJingMaster 分流 + 常用 App 开屏。

只覆盖：百度地图、QQ 音乐、B 站、微博、淘宝开屏。  
银行 / 证券 / 支付（支付宝、微信、银联、建行、工行、招行等）**不解密、不拦广告**。

## 配置

```
https://raw.githubusercontent.com/a510167999-lkj/shadowrocket-ads/main/Shadowrocket-Ads.conf
```

备用：`https://cdn.jsdelivr.net/gh/a510167999-lkj/shadowrocket-ads@main/Shadowrocket-Ads.conf`

导入后点「使用配置」。节点用首页订阅。HTTPS 解密打开一次即可，更新不用重装证书。
